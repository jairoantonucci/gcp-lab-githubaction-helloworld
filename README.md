🚀 GCP + GitHub Actions: Hello World (WIF Edition)
Este repositório faz parte do meu laboratório de aprendizado sobre Infraestrutura como Código (IaC) e CI/CD. O objetivo principal é validar a comunicação segura entre o GitHub Actions e o Google Cloud Platform (GCP) utilizando o Workload Identity Federation (WIF), eliminando a necessidade de chaves JSON estáticas.

🛠️ Tecnologias Utilizadas
Google Cloud Platform (GCP): Provedor de Nuvem.

GitHub Actions: Esteira de CI/CD para automação.

Workload Identity Federation (WIF): Método de autenticação segura via OIDC.

Terraform (Opcional): Gerenciamento de infraestrutura.
